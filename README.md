# くりさがりアドベンチャー

子どもが「くり下がりのある引き算」を、魚釣りや森の仲間集めを楽しみながら学べるブラウザアプリです。

## 学習方法

このアプリは **減加法** に絞っています。

例: `13 - 8`

1. `13` を `10 + 3` と見る
2. `10 - 8 = 2`
3. `2 + 3 = 5`

画面では、10個のまとまりから実際に玉をドラッグ（またはタップ）して取り、残った玉とバラの玉を合わせることで、この流れを視覚的に体験します。

## ゲーム要素

- 🎣 さかなつりモード
- 🌳 もりのなかまモード
- 1問できるたびに魚や森の仲間をコレクション
- −5からスタートし、3問できるごとに −6 → −7 → −8 → −9 を解放
- 進捗・コレクションはブラウザに保存

## 起動

静的ファイルだけで動きます。`index.html` をブラウザで開くか、GitHub Pagesで公開してください。
